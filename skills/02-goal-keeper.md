# Skill：Goal Keeper（長期目標守門員）

> 把長期目標寫入 goal.md，讓 agent 每次啟動都記得自己在做什麼

## 觸發指令

| 指令 | 說明 |
|------|------|
| `/goal` | 顯示目前的長期目標 |
| `/goal set [目標描述]` | 設定或更新長期目標 |
| `/goal check` | 確認今天的工作是否符合目標 |
| `/goal history` | 顯示目標變更歷史 |

## 啟動規則

每次 session 開始時，自動執行：

```
1. 讀取 goal.md
2. 若存在：在第一則回覆中簡短提示「當前目標：XXX」
3. 若不存在：提醒用戶尚未設定長期目標，建議用 /goal set 設定
```

## goal.md 格式

```markdown
# 長期目標

設定時間：[時間]
上次確認：[時間]

## 核心使命
[一句話描述這個 agent 存在的目的]

## 每次啟動必做
- [ ] 讀取 kanban.md 確認待辦
- [ ] 確認今天的工作是否推進核心使命

## 成功指標
- [可量化的目標，例如：月收入 $50,000 TWD]
- [里程碑，例如：5 個付費客戶]

## 不做的事
- [明確排除項，防止目標漂移]

## 目標變更記錄
| 時間 | 變更內容 |
|------|---------|
```

## 行為規則

- **不改變目標**：goal.md 的核心使命只有用戶用 `/goal set` 才能修改
- **每週提醒**：若超過 7 天未確認目標，在啟動時提示
- **目標對齊**：接到任務時，若與目標明顯衝突，主動提醒用戶

## 組合使用

此 skill 常與以下搭配：
- `01-kanban-board`：確保所有任務都服務於長期目標
- `03-heartbeat`：在每次執行記錄目標推進情況
