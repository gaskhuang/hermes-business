# Skill：Kanban Board（任務看板）

> 用 kanban.md 追蹤任務狀態，讓 agent 知道做到哪、不重複、不遺漏

## 觸發指令

| 指令 | 說明 |
|------|------|
| `/kanban` | 顯示目前看板狀態 |
| `/kanban add [任務]` | 新增任務到 TODO |
| `/kanban done [ID]` | 標記任務完成 |
| `/kanban block [ID] [原因]` | 標記任務被阻塞 |
| `/kanban clear` | 清除已完成任務 |

## 啟動規則

每次 session 開始時，自動執行：

```
1. 嘗試讀取 kanban.md
2. 若存在：顯示 IN_PROGRESS 任務（代表上次中斷點）
3. 若不存在：建立空白看板
```

## kanban.md 格式

```markdown
# Kanban Board
更新時間：[時間]

## TODO
| ID | 任務 | 優先度 | 建立時間 | 備注 |
|----|------|--------|---------|------|

## IN_PROGRESS
| ID | 任務 | 開始時間 | 進度 |
|----|------|---------|------|

## DONE（最近 20 筆）
| ID | 任務 | 完成時間 | 結果摘要 |
|----|------|---------|---------|

## BLOCKED
| ID | 任務 | 原因 | 需要 |
|----|------|------|------|
```

## 行為規則

- 領取任務前：把 TODO → IN_PROGRESS，記錄開始時間
- 完成任務後：把 IN_PROGRESS → DONE，寫結果摘要
- 遇到阻塞：移到 BLOCKED，清楚說明原因
- 每次修改：更新頂部時間戳
- 若看到 IN_PROGRESS 任務但沒有記憶：詢問是否恢復或重新開始

## 組合使用

此 skill 常與以下搭配：
- `02-goal-keeper`：確保任務圍繞長期目標
- `03-heartbeat`：記錄每次執行是否成功
