# Skill：Heartbeat（執行健康記錄）

> 每次任務執行後寫入 heartbeat.md，提供健康狀態、失敗診斷、Telegram 告警

## 觸發指令

| 指令 | 說明 |
|------|------|
| `/heartbeat` | 顯示最近執行狀態 |
| `/heartbeat log [狀態] [備注]` | 手動寫入一筆記錄 |
| `/heartbeat alert on` | 連續失敗時啟用 Telegram 告警 |
| `/heartbeat reset` | 清空歷史記錄 |

## 啟動規則

每次 session 開始時，自動執行：

```
1. 讀取 heartbeat.md
2. 若上次狀態為 ❌ 失敗：
   → 顯示失敗原因，詢問是否先診斷再繼續
3. 若連續 3 次失敗：
   → 強制暫停，要求用戶確認後才繼續
4. 若正常：靜默繼續
```

## heartbeat.md 格式

```markdown
# Heartbeat Log

## 最近一次
- 時間：[ISO 時間]
- 狀態：✅ 成功 / ❌ 失敗 / ⚠️ 部分完成
- 執行秒數：[N]
- 完成任務：[N/M]
- 備注：[說明]

## 歷史（最近 20 筆）
| 時間 | 狀態 | 秒數 | 任務 | 備注 |
|------|------|------|------|------|

## 系統狀態
| 元件 | 狀態 | 最後確認 |
|------|------|---------|
| LiteLLM Proxy | — | — |
| Ollama | — | — |
| Telegram Bot | — | — |
| Cloudflare API | — | — |
```

## 自動觸發時機

- 任何任務完成後：自動寫入 ✅
- 任何任務失敗後：自動寫入 ❌ + 錯誤描述
- Cron 執行結束：必定更新，無論成功失敗

## 告警規則

```
連續 2 次 ❌ → 下次啟動時警告
連續 3 次 ❌ → 發送 Telegram 告警（若已設定）
執行超過 30 分鐘 → 記錄 ⚠️ 超時
```

## 組合使用

此 skill 常與以下搭配：
- `01-kanban-board`：任務完成時同步更新兩個文件
- `02-goal-keeper`：記錄每次執行對目標的推進程度
- `07-telegram-notify`：失敗時發送通知
