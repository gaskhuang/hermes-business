# 03｜AI 執行助理（EA-as-a-Service）

## 一句話定位

> 你的 AI 助理不只會回答問題，還會幫你處理 Email、管行事曆、整理會議待辦——讓你專注在真正重要的事。

---

## 為什麼能賺錢

忙碌的創業者、業務、顧問每天面對的問題：

- 收件匣有 300 封信，不知道哪封重要
- 行事曆排得亂七八糟，會議之間沒有緩衝
- 開完會有一堆待辦，但沒人整理成清單
- 每封 Email 都要自己想怎麼回，浪費大量精力

**這是「時間焦慮」，不是能力問題。他們需要的是一個懂他們習慣的助理，而不是又一個 App。**

---

## 商業模式

### 服務內容

```
每日例行：
  ✅ 早上整理收件匣（分類：需要回覆 / 僅供參考 / 垃圾）
  ✅ 摘要重要 Email，附草稿回覆（人工確認後發送）
  ✅ 整理當日行事曆，提醒注意事項
  ✅ 彙整昨日未完成待辦

每週例行：
  ✅ 週報：完成了什麼、下週重點、需要做決定的事
  ✅ 行事曆空白時段建議（哪時間適合深度工作）
  ✅ 重要關係維護提醒（久未聯繫的重要客戶）

隨時可用：
  ✅ Telegram 下指令：「幫我約下週二跟 XX 開會」
  ✅ 草擬 Email、提案、會議摘要
  ✅ 搜尋過去的對話、文件、決策紀錄
```

### 定價

| 方案 | 內容 | 月費 |
|------|------|------|
| 輕量版 | Email 分類 + 行事曆整理，每日報告 | $5,000 TWD |
| 標準版 | 含草稿回覆、週報、Telegram 互動 | $8,000 TWD |
| 全配版 | 含重要關係維護、文件整理、即時回應 | $15,000 TWD |

> 對客戶來說：比請一個行政助理便宜，但 24 小時可用  
> 對你來說：大部分工作由 Hermes Agent 自動完成，你只做最後審核

## 競爭優勢

**個人化設定，不是通用工具。**

| 通用 AI 工具（ChatGPT, Gemini）| 你的 EA 服務 |
|-------------------------------|--------------|
| 每次要重新說明背景 | 記住客戶的偏好、常用聯絡人、習慣 |
| 只回答問題，不主動 | 每天主動整理、提醒、報告 |
| 需要客戶自己操作 | 幫客戶做完，只要確認 |
| 不接 Email/行事曆 | 直接整合 Gmail + Google Calendar |

## 典型工作流程

```
早上 8:00
  → Hermes 掃描過去 12 小時的 Gmail
  → 分類：5 封需要回覆、12 封可略過、3 封重要通知
  → 草擬回覆草稿（附建議語氣：正式/輕鬆）
  → 整理今日行事曆，標注需要準備的事項
  → 發送 Telegram 晨報給客戶

客戶收到晨報後
  → 確認草稿（直接回「好」或微調後發送）
  → 可追加指令：「那封 XX 的信先不要回」「幫我看一下附件」

下午開完會
  → 客戶：「剛才開完會，幫我整理一下待辦」
  → Hermes 根據逐字稿或摘要，產出結構化清單
  → 同步到 Notion 或直接 Email 給與會者
```

## 執行計畫

### Phase 1：驗證（0–2 個月）

```
目標：找 2–3 個忙碌的創業者朋友，免費幫他們試用 1 個月
關鍵指標：每週省下幾小時？最有價值的功能是什麼？
產出：真實 testimonial + 具體數字
```

### Phase 2：定價銷售（2–4 個月）

```
用 case study 開始收費
目標客群：年收入 500 萬以上的創業者、業務主管、顧問
切入點：LinkedIn、創業社群、介紹
目標：5 個付費客戶
```

### Phase 3：規模化（4 個月後）

```
建立「客戶偏好設定表」（標準化 onboarding）
把 Hermes 設定模板化（每個新客戶 < 2 小時上線）
考慮分層：自己服務高單價客戶，低單價用 SaaS 化產品
```

## 技術架構

```
資料接入
  ├── Gmail（OAuth，讀取 + 草稿）
  ├── Google Calendar（讀取 + 建立事件）
  ├── Notion（選配，待辦 + 筆記同步）
  └── Telegram（客戶下指令介面）
          ↓
    Hermes Agent（每日定時 + 即時回應）
    ├── Email 分類模型（依客戶偏好訓練）
    ├── 草稿生成（語氣、格式依客戶風格）
    └── 行事曆分析（衝突偵測、緩衝建議）
          ↓
    每日報告（Telegram 晨報）
    + 即時互動（Telegram Bot）
```

## 銷售話術

**開場（針對創業者/業務）：**

> 「你每天花多少時間在看 Email？大部分人說兩小時以上。我最近在幫幾個創業者建一個『AI 執行助理』，每天早上幫你整理信件、草擬回覆、整理行事曆，你只要花 10 分鐘確認就好。第一個月免費試用，我只需要你的 Gmail 授權。有興趣試試看嗎？」

---

## 關鍵銷售點

- **隱私保護**：草稿由 AI 生成，但一定要人工確認才發送
- **學習曲線**：前兩週 AI 可能不夠準確，但會快速學習客戶風格
- **可退出**：隨時可以停止，所有資料歸客戶所有，不鎖定
