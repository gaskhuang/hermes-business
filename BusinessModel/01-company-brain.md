# 01｜企業知識管理服務（公司大腦）

## 一句話定位

> 把公司散落各地的知識，整合成一個會自動更新的「公司大腦」，讓新人一週上手、老員工不再找資料。

---

## 為什麼能賺錢

企業裡每天有大量的會議、決策、試算表，但這些知識散落在各地：

- 會議記錄在某人的 Google Drive
- 決策原因只存在主管腦袋裡
- SOP 三年沒更新，還在 Dropbox 的某個角落

**新人要花幾個月才能追上，老員工也每天在重複找資料。**

這是每家公司都有的痛點，且現有工具（Notion AI、Confluence）都是通用的，沒有針對特定產業設定好的解法。

---

## 商業模式

### 服務內容

```
建置：
  ✅ 接入 Notion / Google Drive / 會議記錄 / Email
  ✅ 建立知識分類架構（依公司業務客製）
  ✅ 訓練 agent 識別公司術語與流程
  ✅ 建立「提問介面」：員工用 Telegram 問，agent 從知識庫找答案

每月自動：
  ✅ 整理當月會議記錄，更新知識庫
  ✅ 摘要重要決策，寫進 wiki
  ✅ 回報知識庫健康狀態（哪些資料過期、哪些缺漏）
```

### 定價

| 方案 | 內容 | 月費 |
|------|------|------|
| 基本版 | 接入 1 個資料來源，月更新 2 次 | $500 TWD |
| 標準版 | 接入 3 個資料來源，週更新 | $1,500 TWD |
| 完整版 | 無限資料來源，即時同步，含員工提問介面 | $3,000 TWD |

> 對企業來說：比招一個行政助理便宜 10 倍  
> 對你來說：成本只有 API 費用（每月 $50–$200 TWD）

## 競爭優勢

**做垂直產業，不做通用工具。**

| 產業 | 特殊需求 | 你能提供的差異 |
|------|----------|----------------|
| 建築業 | 工程術語、圖說管理、發包記錄 | 預設建築業知識架構 |
| 律師事務所 | 案件分類、法條引用、客戶保密 | 法律文件處理流程 |
| 廣告代理商 | 提案、客戶 brief、版本管理 | 創意資產整理架構 |
| 貿易公司 | 報價單、供應商資料、出貨記錄 | 商務文件自動歸類 |

## 執行計畫

### Phase 1：驗證（0–2 個月）

```
目標：找 3 個朋友的公司，免費幫他們建
產出：3 個真實 case study（有數據：省了幾小時、找資料快了多少）
```

### Phase 2：定價銷售（2–4 個月）

```
用 case study 開始收費
鎖定 1 個垂直產業深耕
目標：5 個付費客戶
```

### Phase 3：規模化（4 個月後）

```
建立產業模板（一套架構複製給同產業客戶）
把建置流程標準化，縮短每個客戶的建置時間
```

## 技術架構

```
資料來源
  ├── Google Drive（文件、試算表）
  ├── Gmail（重要信件）
  ├── Notion（現有知識庫）
  └── 會議記錄（Zoom、Google Meet 逐字稿）
          ↓
    Hermes Agent（定期爬取、整理、分類）
          ↓
    向量資料庫（儲存可搜尋的知識片段）
          ↓
    Telegram Bot（員工提問介面）
```

## 銷售話術

**開場（針對中小企業主）：**

> 「你們公司有沒有這個問題：新人來了，要花很久才能上手，因為東西散在各地找不到？或是老員工離職，他知道的東西就跟著走了？我最近在幫幾家公司建一個『公司大腦』，把所有的會議記錄、SOP、決策都整合在一起，員工用 LINE 問就能找到答案。免費幫你試做一個月，有興趣嗎？」
