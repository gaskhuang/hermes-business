# 06｜AI 費用控制顧問服務

## 一句話定位

> 你的 AI Agent 帳單不應該超過你的水電費——用混合路由 + 本地模型，把每月 $150 USD 壓到 $5 USD。

---

## 為什麼能賺錢

**費用是社群兩個最核心的焦慮之一。**

典型客戶現況：
```
用 Claude Sonnet 跑所有 agent 任務
  → 分類 Email：Sonnet（大砲打小鳥）
  → 確認指令「好的，已收到」：Sonnet（完全浪費）
  → 月底帳單 $100–$200 USD
  → 開始懷疑「AI 到底值不值得用」
```

**真相：80% 的 agent 任務根本不需要 Sonnet 等級的模型。**

| 任務類型 | 佔比 | 需要的模型 | 現在用的 |
|----------|------|----------|---------|
| 分類/格式化/摘要 | 60% | Haiku（$0.25） | Sonnet（$3） |
| 分析/草稿 | 30% | Sonnet（$3） | Sonnet（正確） |
| 複雜推理 | 10% | Opus（$15） | Sonnet（不夠） |

**換句話說：客戶現在的問題是「簡單事情過貴 + 困難事情反而不夠強」。**

---

## 服務內容

```
費用審計（一次性）：
  ✅ 分析客戶過去 30 天的 API 使用記錄
  ✅ 找出「大砲打小鳥」的呼叫（成本最高的浪費點）
  ✅ 產出費用優化報告（預計可省多少 %）

建置（一次性）：
  ✅ 部署 LiteLLM Proxy（統一路由層）
  ✅ 設定三層模型路由（fast / standard / powerful）
  ✅ 整合本地 Ollama（選配，需有 Mac M 系列）
  ✅ 設定月費用上限 + Telegram 告警
  ✅ 修改 Hermes soul.md，加入路由使用規則

每月維護：
  ✅ 月費用報告（實際 vs 優化後對比）
  ✅ 路由規則調整（隨客戶使用模式優化）
  ✅ 新模型評估（市場有更便宜的選項時主動建議）
```

## 競爭優勢

**從帳單數字說話，不靠說服。**

1. **先做免費審計**：拿到客戶 API key 看 30 天記錄，告訴他「你浪費了 $X TWD」
2. **建置前先估算 ROI**：「建置費 $10,000，6 個月回本，之後每月淨省 $2,000」
3. **月費從省下來的錢裡扣**：客戶心理上不是「花錢」，是「少花一點錢」

---

## 兩大核心技術

### A. 混合路由（Mixed Routing）

```
原理：不同複雜度的任務，用對應等級的模型

快速模型（$0.25/1M tokens）← 分類、摘要、格式化、確認
  ↑ 60% 的任務走這裡
標準模型（$3/1M tokens）← 分析、草稿、研究
  ↑ 30% 的任務走這裡  
強力模型（$15/1M tokens）← 複雜推理、架構設計
  ↑ 10% 的任務走這裡

工具：LiteLLM Proxy（開源，免費自架）
```

### B. 本地模型（Local Models）

```
原理：Mac M 系列統一記憶體，跑 32B–70B 模型接近雲端品質

隱私任務 → 本地 Ollama（資料不出機器）
高頻雜事 → 本地 Phi-4（速度快，成本為零）
程式碼 → 本地 Qwen2.5-Coder（媲美 GPT-4o）

硬體：Mac M4 Pro 48GB（$60,000 TWD）
→ 大量使用下，3–6 個月回本
```

## 執行計畫

### Phase 1：驗證（0–2 個月）

```
目標：拿 2–3 個人的 API 使用記錄，做免費審計
產出：
  - 「優化前 vs 優化後」費用對比報告
  - 實際建置，驗證省錢數字
```

### Phase 2：定價銷售（2–4 個月）

```
用審計報告當敲門磚
在 Reddit / Discord / Telegram 社群分享「我幫人省了 X%」的案例
目標：5 個付費客戶
```

### Phase 3：規模化（4 個月後）

```
把 LiteLLM 設定模板化（30 分鐘完成建置）
提供 SaaS 版本：客戶不需要自架，走你的 proxy
月費收 token 用量的 10–15%（成為代理商模式）
```

**開場（針對已在用 AI Agent 的人）：**

> 「你上個月 AI API 花了多少？大部分人都覺得太貴，但又不知道從哪裡省。我幫幾個人做了費用審計，發現他們 60% 的 API 呼叫都是用最貴的模型做最簡單的事，像是分類 Email 或格式化輸出。我可以免費幫你看一下上個月的記錄，告訴你能省多少，有沒有興趣？」

**審計結果出來後：**

> 「你上個月花了 $120 USD，其中 $80 可以省下來。建置費是 $10,000 TWD，2 個月就回本，之後每個月多 $2,000 TWD 的利潤。要不要我幫你裝？」
