## 切入順序建議

```
第一步：EA-as-a-Service（最快驗證）
  → 找 2–3 個朋友/創業者免費試用，驗證流程

第二步：Second Brain + Agent Ops（技術門檻低，社群剛需）
  → 從 Reddit/Discord 找已在用 Hermes 的用戶
  → 解決他們最痛的兩個問題：記憶消失 + Agent 卡住

第三步：企業知識管理（最容易規模化）
  → 選定一個垂直產業（代理商、律所、建築業），深耕

第四步：IT 自動化顧問（單價最高）
  → 需要有伺服器管理底子，適合有技術背景的人
```

---

## 服務組合建議

```
入門組合（給個人 Hermes 用戶）：
  Second Brain + Agent Ops = 每月 $3,500–$7,000
  → 記憶不消失 + Agent 自主跑，基礎架構全搞定

進階組合（給企業）：
  Agent Ops + 公司大腦 + EA = 每月 $10,000–$25,000
  → 自動化員工 + 知識管理 + 執行助理，全套 AI 辦公
```

---

## 共同原則

- **賣服務，不賣工具**：客戶付月費，你幫他建好維護好
- **從免費 case study 開始**：3 個真實案例比 100 頁簡報有力
- **Telegram 是介面**：讓客戶用熟悉的工具下指令，降低學習門檻
