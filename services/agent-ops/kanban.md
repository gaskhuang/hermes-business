## 📝 Agent 操作規則

1. **啟動時**：先讀這個文件，找 IN_PROGRESS 任務（代表上次未完成）
2. **領取任務**：把 TODO 移到 IN_PROGRESS，寫上開始時間和自己的 Agent ID
3. **完成任務**：把 IN_PROGRESS 移到 DONE，寫結果摘要
4. **遇到阻塞**：移到 BLOCKED，清楚說明原因和需要什麼協助
5. **每次更新**：修改頂部的「更新時間」
