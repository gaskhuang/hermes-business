# Agent Ops 一鍵部署指令

> 把以下全文貼入你的 Hermes / OpenClaw，Agent 會自動完成安裝。

---

```
請幫我安裝「Agent Ops 長跑架構」，依以下步驟執行：

## 步驟 1：建立三個核心文件

建立 goal.md：
---
# Agent 長期目標

## 核心使命
[請在這裡填入你的 Agent 的核心任務]

## 每次執行必做
- [ ] 讀取 kanban.md 確認待辦
- [ ] 讀取 heartbeat.md 確認上次狀態
- [ ] 完成任務後更新兩個文件

## 絕對不做
- 不重複執行已在 DONE 的任務
- 不在不確定時靜默失敗
---

建立 kanban.md：
---
# Agent Kanban Board
更新時間：[現在時間]

## TODO
| ID | 任務 | 優先度 | 備注 |
|----|------|--------|------|

## IN_PROGRESS
| ID | 任務 | 開始時間 | 進度 |
|----|------|---------|------|

## DONE（最近 20 筆）
| ID | 任務 | 完成時間 | 結果 |
|----|------|---------|------|

## BLOCKED
| ID | 任務 | 阻塞原因 | 需要 |
|----|------|---------|------|
---

建立 heartbeat.md：
---
# Agent Heartbeat

## 最近執行
- 時間：[現在時間]
- 狀態：🟡 初始化
- 備注：Agent Ops 剛安裝完成

## 執行歷史
| 時間 | 狀態 | 秒數 | 備注 |
|------|------|------|------|
---

## 步驟 2：設定你的 soul.md / AGENTS.md

在文件頂部加入：

---
# Agent 啟動規則（Agent Ops）

每次啟動時，依序執行：
1. 讀取 goal.md → 確認使命
2. 讀取 kanban.md → 找到 IN_PROGRESS 任務（代表上次中斷），優先恢復
3. 讀取 heartbeat.md → 若上次失敗，先診斷原因
4. 自主執行任務，每完成一步更新 kanban.md
5. 全部完成後更新 heartbeat.md
---

## 步驟 3：驗證安裝

確認以下文件存在：
- goal.md ✅
- kanban.md ✅  
- heartbeat.md ✅

然後說「安裝完成，請確認這三個文件的位置和內容是否正確」
```
